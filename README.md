# Интегратор математических выражений

## Описание

Программа для символьного интегрирования математических выражений. Поддерживает многочлены, рациональные дроби и элементарные функции.

## Возможности

- Интегрирование многочленов
- Интегрирование рациональных дробей
- 25 табличных интегралов (sin, cos, e^x, 1/x, arcsin, arctg и другие)
- Консольный и графический интерфейс
- Проверка корректности ввода

## Установка

Скопируйте все файлы проекта в одну папку. Убедитесь, что установлен Python версии 3.8 или выше.


## Запуск

Консоль: python main.py
GUI: python gui.py

## Пример

Введите переменную интегрирования (например х): х

Введите функцию: 2x

Вывод: ∫ (2x) dx = x^2 + C
